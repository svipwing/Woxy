### 🏗 软件架构

基于 **Google Blockly** 开发，采用 **GPL-3 许可证**。

### 💻 安装教程

1. 下载发行版（如长期未更新，请拉取最新 `master` 分支作为源码，并删除 `.git` 目录）。
2. 解压到主机。
3. 访问 `index.html` 开始使用。

### ⚡ 使用说明

1. 拖拽积木进行编程。
2. 点击 **运行代码**，查看效果并调整。
3. 编写完成后，点击 **生成代码**，复制到 HTML 文件中。

### ⚠ 注意事项

1. 首次使用或遇到问题，请查看 **新手指引** 或加入 QQ 群：135452025。
2. 本工具仍在开发阶段，仅供初学者学习，**请勿用于生产环境**。
